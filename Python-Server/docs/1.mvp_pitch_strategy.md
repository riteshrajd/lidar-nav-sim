# MVP Pitch Strategy: The Agentic Checkpoint Compass

To secure funding as a solo developer, you must demonstrate a system that *feels* highly intelligent but relies entirely on feasible, off-the-shelf logic. We are abandoning impossible 3D NavMeshes. Instead, we are treating Haptic-Nav as a **Macro-Navigator** (directing the user checkpoint to checkpoint), completely trusting the user's white cane to act as their **Micro-Navigator** (avoiding immediate bumps and chairs).

Here are the 3 Demo Scenarios to build your Unity simulation around for the pitch.

---

## Scenario 1: The Direct Compass (The Baseline)
This is the easiest scenario to program and proves the base functionality of the Haptic integration.
* **The Goal:** "Take me to the exit door."
* **The Environment:** A simple, mostly open metro station where the exit is immediately in the camera's frame.
* **The Logic:** The user presses `[V]`. The VLM identifies the door and says `direction: front-right`. The belt buzzes front-right. The user walks directly toward the buzz. They use their white cane to dodge a trash can along the way.
* **Why it matters:** Proves the basic latency from: Camera -> Cloud -> Belt vibration.

---

## Scenario 2: The Agentic Checkpoint (The "Sweet Spot" Recommended Approach)
This is the exact approach you pitched, and it is brilliant. It fakes complex autonomous pathfinding by letting the VLM "reason" step-by-step.
* **The Goal:** "Take me to the upper floor of the mall."
* **The Environment:** A complex multi-stage environment where the final goal is impossible to see from the start line.
* **The Logic:** 
  1. The VLM executes an Agentic prompt: *"Identify the next logical visual milestone to reach the goal."* 
  2. The VLM sets **Checkpoint 1:** The base of the Escalator (30m away, direct path). The belt guides them to the escalator.
  3. The user rides the escalator up.
  4. The user hits `[V]` again. The VLM sets **Checkpoint 2:** The target shop, which is now in view. 
* **Why it matters:** This is the core patentable IP of your startup. You are proving that AI can break down impossible global tasks into bite-sized, visible haptic steps!

---

## Scenario 3: The Dynamic Recovery (The "WOW" Factor)
Investors will ask, *"What happens if the path is blocked?"* You use this scenario to prove the system doesn't crash like a dumb robot.
* **The Goal:** "Take me to the empty table."
* **The Environment:** A busy cafe. The direct path to the table gets completely blocked by a group of people halfway through.
* **The Logic:** 
  1. The user begins walking to the table, but hits a wall of people.
  2. The user taps the belt: *"I'm blocked."*
  3. The belt takes a new image. The VLM observes the massive obstruction blocking its original target.
  4. The VLM drops a **temporary detour checkpoint**: *"The path is blocked. Turn 90 degrees left to walk past the counter."* Once past the counter, the user asks again, and it re-targets the table.
* **Why it matters:** This proves real-time reasoning and environmental awareness without needing expensive SLAM algorithms.

---

## The Verdict & Recommendation

You should **100% focus entirely on the Agentic VLM Checkpoint approach (Scenario 2).** 

**Why it works for a Solo Dev:**
1. **Zero Math:** You don't have to code A* pathfinding. The VLM automatically handles the "pathfinding" by simply telling you where the next milestone is. 
2. **Symbiosis with the White Cane:** Building an obstacle-avoiding haptic belt requires insane millimeter accuracy. Building a "Checkpoint Compass" doesn't. You can literally tell investors: *"Haptic-Nav doesn't replace the White Cane; the Cane handles the immediate physical world, Haptic-Nav serves as the cognitive brain telling them where to aim the cane."*

If we adopt this strategy, we just need to refine your `main_pipeline.py` prompt to ask the AI to **set the nearest visible checkpoint** rather than trying to map the entire room.
